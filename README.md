### Ejercicio 2: Métodos void para acciones directas

Objetivo: Comprender el uso de "void" en métodos que realizan acciones sin devolver valores.

### Ejercicio 8: Instanciación e Invocación en el Main

### Conclusión

Mediante esta práctica se reforzaron los conocimientos sobre la creación y utilización de métodos en Java. Los ejercicios permitieron comprender cómo enviar información mediante parámetros, devolver resultados con "return" y utilizar métodos "void" para mostrar información. Además, se practicó la creación de objetos y la validación de datos, conocimientos importantes para continuar aprendiendo programación orientada a objetos.
